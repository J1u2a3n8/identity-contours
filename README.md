## Description

Computer vision project analyzing shape contours for object identification. Implements contour detection, approximation, hierarchy analysis, and shape matching using OpenCV. Applications in industrial inspection and OCR preprocessing.

## Architecture

CV Pipeline: Image Acquisition → Preprocessing → Contour Detection → Feature Extraction → Shape Matching → Classification

## Quick Start

### Prerequisites

Python 3.10+, pip/poetry, Jupyter Lab

### Installation

```bash
# Clone
git clone https://github.com/J1u2a3n8/identity-contours.git
cd identity-contours

pip install -r requirements.txt
# jupyter lab
```

### Usage

```bash
jupyter notebook notebooks/contour-analysis.ipynb
```

## Testing

```bash
pytest tests/
```
